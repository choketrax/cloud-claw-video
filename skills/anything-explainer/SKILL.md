# Anything2Explainer Client Skill

Use this skill to submit, track, and retrieve narrated motion-graphics explainer videos generated by the connected `explainer-test-worker` service (`https://explainer-test-worker.dl-56e.workers.dev`).

## Tools & Commands

Run helper scripts via the container's Python environment:
`python3 /home/openclaw/clawd/skills/anything-explainer/scripts/explainer_client.py <command> [args]`

### 1. Create an Explainer Video Job
Submit a topic or custom script:
```bash
python3 /home/openclaw/clawd/skills/anything-explainer/scripts/explainer_client.py create \
  --topic "AI cost audit and spend control pack for engineering leaders" \
  --duration 30 \
  --purpose education \
  --language en \
  --audience "Engineering Leaders"
```

Parameters:
- `--topic`: (Required) Subject of the video.
- `--duration`: Target duration in seconds: `30` (30s preview), `60` (1 min), `120` (2 min), `300` (5 min), `480` (8 min).
- `--purpose`: `education`, `sales`, `onboarding`, or `marketing`.
- `--language`: `en` (English) or `zh` (Chinese).
- `--audience`: Target demographic or audience.
- `--script-text`: Optional custom narration script.
- `--script-file`: Optional path to markdown or text script file.
- `--scene-direction`: Optional visual styling notes.

Returns JSON with `jobId` (e.g. `exp_2df2b55a369b48ff`).

### 2. Check Job Status
```bash
python3 /home/openclaw/clawd/skills/anything-explainer/scripts/explainer_client.py status <jobId>
```
Reports `status` (`queued`, `running`, `completed`, `failed`), `progress` (0–100%), and `currentStage`.

### 3. Wait and Automatically Download
Polls until rendering is complete and downloads the resulting MP4:
```bash
python3 /home/openclaw/clawd/skills/anything-explainer/scripts/explainer_client.py wait <jobId> \
  --download-to /work/jobs/<jobId>/explainer.mp4 \
  --interval 10
```

### 4. Fetch Artifacts
Retrieve the generated script, QC check, or manifest:
```bash
# Get narration script
python3 /home/openclaw/clawd/skills/anything-explainer/scripts/explainer_client.py artifact <jobId> script/narration.md

# Get QC report
python3 /home/openclaw/clawd/skills/anything-explainer/scripts/explainer_client.py artifact <jobId> metadata/qc.json

# Get Manifest
python3 /home/openclaw/clawd/skills/anything-explainer/scripts/explainer_client.py artifact <jobId> metadata/manifest.json
```

### 5. Downstream Mastering with FFmpeg-Skill
Once the explainer MP4 is downloaded, you can hand it off to `ffmpeg-skill` for:
- Loudness normalization (`loudness.py -o mastered.mp4 --target -14`)
- Platform delivery format (`export.py --platform reels -o reels.mp4`)
- Quality inspection (`look.py --tiles 3x2`)
